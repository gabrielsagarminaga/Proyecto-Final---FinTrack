# FinTrack
Programa en Python para el control y administracion de gastos personales.

## Descripción del proyecto
Este es un programa en Python que permite registrar ingresos y gastos personales, organizarlos por categoría y calcular el balance total del usuario.
El objetivo del proyecto es ayudar a las personas a llevar un mejor control de sus finanzas personales de forma sencilla desde la consola.

## Funcionalidades que se encuentran en el programa

- Agregar ingresos
- Agregar gastos
- Ver historial de movimientos
- Filtrar movimientos por categoría
- Calcular balance total
- Almacenamiento persistente con JSON
- Búsqueda recursiva por categoría
- Manejo de errores para entradas inválidas
